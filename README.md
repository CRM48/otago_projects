# Otago University Portfolio

This repository contains selected projects from my Bachelor's degree at the University of Otago:

- **Bachelor of Science and Commerce**, majoring in Computer Science and Finance | University of Otago (2021–2024)

The projects cover a range of areas including computer graphics, artificial intelligence, image processing, web development, databases, networking and algorithms.

## Projects

- [**3D Rendering Engine**](3d_rendering_engine) – 3D graphics and rendering using C++ and OpenGL
- [**Image Feature Matching**](image_feature_matching) – Computer vision, feature detection and image stitching
- [**Birds of Aotearoa**](birds_of_aotearoa) – Full-stack web application with a relational database
- [**ANDIE: A Non-Destructive Image Editor**](andie) – Java image editing application
- [**Game Playing AI**](game_playing_ai) – Artificial intelligence and game-playing algorithms
- [**Vintage Vault**](vintage_vault) – Web application development and database integration
- [**HTTP Proxy Cache**](http_proxy_cache) – HTTP networking and caching in Java
- [**Rational Arithmetic**](rational_arithmetic) – Mathematical computation and object-oriented programming
- [**Counting it Up**](Counting%20it%20up) – Efficient computation of binomial coefficients
- [**Where in the World is CS**](WhereInTheWorldIsCS) – Coordinate conversion and geographical visualisation
- [**Snowflake**](Snowflake) – Recursive fractal generation and GUI development
- [**Dates**](Dates) – Date validation, parsing and formatting

## Project Details

### 3D Rendering Engine (2024)

- A C++ graphics application that renders interactive 3D scenes using OpenGL.
- Implements 3D model loading, textures, transformations, camera controls and lighting.
- Supports shader-based rendering and post-processing effects, including a configurable ripple effect.
- Demonstrates knowledge of computer graphics, the rendering pipeline, GLSL shaders and C++ development.

### Image Feature Matching (2024)

- A C++ computer vision project that detects and matches features between two images.
- Uses feature matching and geometric transformations to align overlapping images and construct a mosaic.
- Demonstrates how images can be matched despite differences in position and perspective.
- Covers image processing, computer vision algorithms and geometric estimation.

### Birds of Aotearoa (2023)

- A full-stack web application for viewing and managing information about New Zealand birds.
- Built using Node.js, Express, EJS and MySQL, with a database storing bird information and related records.
- Supports operations such as searching, adding, updating and deleting bird entries, including associated images.
- Demonstrates web development, relational database design, SQL queries and server-side programming.

### ANDIE: A Non-Destructive Image Editor (2022)

- A Java desktop image editor developed as a group project, allowing images to be edited without permanently changing the original.
- Includes colour adjustments, filters, transformations, selections and other image manipulation tools.
- Uses a graphical interface to apply and manage image editing operations.
- Demonstrates object-oriented programming, GUI development, image processing and collaborative software development.

### Game Playing AI (2024)

- An artificial intelligence project exploring how algorithms can make decisions in competitive games.
- Implements game-playing strategies that evaluate possible moves and select actions based on the current game state.
- Explores search algorithms, decision-making and the trade-off between computational cost and playing performance.
- Demonstrates the application of AI techniques to adversarial problems.

### Vintage Vault (2024)

- A web application project involving the development of an interactive, data-driven website.
- Combines front-end interfaces with back-end functionality and data management.
- Demonstrates how different parts of a web application work together to support user interactions.
- Covers web development, application structure and database integration.

### HTTP Proxy Cache (2024)

- A Java HTTP proxy server that sits between a client and an origin server, forwarding requests and responses.
- Implements caching so previously requested resources can be served locally without contacting the origin server again.
- Handles different types of content, including text, images and larger files.
- Demonstrates socket programming, HTTP communication, binary data handling and network caching.

### Rational Arithmetic (2023)

- A project implementing arithmetic operations on rational numbers represented as fractions.
- Supports mathematical operations while maintaining valid and simplified rational number representations.
- Handles the logic required for fraction calculations rather than relying only on floating-point arithmetic.
- Demonstrates object-oriented programming, mathematical algorithms and input validation.

### Counting it Up (2023)

- A collection of eight implementations for calculating binomial coefficients, representing the number of ways to choose *k* items from *n*.
- Explores methods for calculating large coefficients while working within the limits of 64-bit integer types.
- Progressively improves the algorithms through rearranged formulas, reduced intermediate values and approaches based on Pascal's triangle.
- Demonstrates algorithm design, numerical accuracy, efficiency and the importance of avoiding integer overflow.

### Where in the World is CS (2023)

- A program that accepts geographical coordinates and displays their locations on a map.
- Supports coordinates in degrees/minutes/seconds, degrees/decimal minutes and decimal degrees.
- Converts different coordinate formats into a consistent representation and exports geographical data using GeoJSON.
- Demonstrates input validation, coordinate conversion, data formatting and geographical visualisation.

### Snowflake (2023)

- A Java graphical application that generates Koch snowflakes of different orders.
- Uses recursion to repeatedly subdivide line segments, producing increasingly complex fractal patterns.
- Provides an interactive GUI for selecting and displaying the desired snowflake order.
- Demonstrates recursive algorithms, geometry and graphical user interface development.

### Dates (2023)

- A program that accepts user-provided dates, validates them and converts them into a consistent output format.
- Checks both the input structure and whether the date itself is valid.
- Handles calendar rules and invalid inputs to prevent incorrect dates from being accepted.
- Demonstrates string processing, conditional logic, input validation and basic software testing.
